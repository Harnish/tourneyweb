Help

A quick guide to running a tournament in TourneyWeb, organized by role.

Tournament Directors

  1. Create a tournament — "+ New Tournament" in the nav bar. Set the sport, location, start date, and a default division ranking order (applied to new divisions automatically).
  2. Add divisions — from Manage → Divisions, add one division per age group / skill level.
  3. Add teams — from Manage → Teams, assign each team to a division.
  4. Schedule games — from a division's Manage Games page, add games with location, date/time, and umpire.
  5. Enter scores — directors and staff can score games from the public games page; standings update immediately.
  6. Configure rankings — per division, choose the tiebreaker order (wins, head-to-head, runs allowed, run differential, etc.) from the division edit page. The public division page shows "Ranked by: …".
  7. Run a bracket — once pool play is done, click Start Bracket on the division. Choose:
    • Single elimination — any team count; uneven counts get byes in round 1.
    • Double elimination — only offered when the team count is an exact power of 2 (4, 8, 16, 32). Teams get a second life in the losers bracket; if the losers-bracket team wins the grand final, a bracket-reset game decides the champion.
    Review the auto-seeded order on the seed page (drag rows or use the ↑/↓ buttons), then Lock Bracket to generate games. Scores entered afterward automatically advance winners (and losers, for double elimination) through the bracket.
  8. Invite staff and coaches — from Manage → Roles, invite people by email; the role is applied automatically when they register. director gets full tournament management, staff can enter scores, coach manages one team's roster.
  9. Fields, rules, news, extras — add field locations (with a map pin) under Manage → Locations, write per-division rules, post news, and add a freeform "extras" page from the tournament's manage menu.

Coaches

  • Roster — from your team's roster page, add players (name, number, position, handedness). The public team page shows a condensed roster (first initial + last name).
  • Team QR code & printable sheet — every team page has a QR code linking to that team's public page, and a Printable Team Sheet link with the roster and a print button — handy to hand out or post at the field.

Staff

  • Staff see a Score link on the public games page for any game in their assigned tournament, and can enter final scores there.

Everyone

  • The tournament home page lists divisions, standings, fields, and news. Division and team pages are public — no login required to view schedules, standings, or brackets.
  • If a tournament is running with disabledelete turned on, delete buttons are hidden everywhere to prevent accidental changes during a live event.

Questions or found a bug? See the About page for the project's GitHub repository.
