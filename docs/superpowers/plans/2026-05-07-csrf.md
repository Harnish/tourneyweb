# CSRF Protection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add gorilla/csrf middleware to protect all admin POST forms from cross-site request forgery.

**Architecture:** Wrap the httprouter with `csrf.Protect(...)` middleware in `main.go`. Each handler that renders a POST form injects the token via `csrf.Token(r)` as a hidden field. Config gains a `CSRFKey` field (32-byte hex string) decoded at startup.

**Tech Stack:** `github.com/gorilla/csrf`, Go standard `encoding/hex`

```go
)
```

- [ ] **Step 2: Add decodeCSRFKey function**

Add this function at the bottom of `main.go`:
```go
func decodeCSRFKey(hexKey string) []byte {
	key, err := hex.DecodeString(hexKey)
	if err != nil {
		log.Fatalf("csrfkey config: must be a valid hex string: %v", err)
	}
	if len(key) != 32 {
		log.Fatalf("csrfkey config: must decode to exactly 32 bytes (64 hex chars), got %d bytes", len(key))
	}
	return key
}
```

- [ ] **Step 3: Wire the middleware**

In `main.go`, replace:
```go
log.Fatal(http.ListenAndServe(":"+cfg.Port, wh.RequestLogger(router)))
```
With:
```go
csrfKey := decodeCSRFKey(cfg.CSRFKey)
csrfMiddleware := csrf.Protect(csrfKey, csrf.Secure(false))
log.Fatal(http.ListenAndServe(":"+cfg.Port, wh.RequestLogger(csrfMiddleware(router))))
```
